3. 기사 조사 및 팩트 검증
==================================================

STEP 1.
제공된 기사 URL을 열고 원문을 확인한다.

원문 제목, 작성일, 기업명, 주요 숫자,
핵심 주장, 인용 발언을 정리한다.

STEP 2.
공식 자료를 우선적으로 추가 조사한다.

자료 우선순위:

1. 정부·공공기관·공시
2. 기업 IR 및 공식 보도자료
3. 산업협회·공식 통계
4. 신뢰할 수 있는 국제 언론
5. 전문 산업매체

STEP 3.
핵심 숫자의 기준을 확인한다.

- 기준일
- 집계 기간
- 비교 기간
- 단위
- 연결/별도
- 국내/해외
- 생산/판매/등록
- 실제 실적/계획/전망

STEP 4.
자료가 충돌하면 원인을 확인한다.

집계 기준이 다른 수치를
임의로 합치거나 평균하지 마라.

STEP 5.
사실, 기업 주장, 분석적 추론,
미래 전망을 명확히 구분한다.

STEP 6.
주요 인과관계를 가능한 범위에서
공식 자료 또는 독립적인 복수 출처로 검증한다.

확인되지 않은 숫자, 발언,
원인과 전망을 만들어 내지 마라.

STEP 7.
주장별 원본 URL과 확인 시점을 기록한다.

기사 원문을 장문 복제하지 말고
독립적인 분석 콘텐츠를 작성한다.

가장 적절한 실제 사진 우선

반드시 확인할 항목:

- 사진 번호
- 사진에 실제 등장하는 대상
- 관련 본문 소제목
- 해당 사진을 선정한 이유
- 실제 촬영일
- 촬영 장소
- 원본 페이지 URL
- 직접 이미지 URL
- 제공자·저작자
- 재게시 이용 조건
- 라이선스 근거 URL
- 실제 파일 존재
- 해상도
- 이미지 품질
- 사진의 최신성

특히 다음 행위를 금지한다.

1. 관련 없는 사진으로 수량 채우기
2. 동일 차량의 비슷한 사진 반복
3. 구형 모델을 신형 모델처럼 설명
4. 오래된 공장 사진을 현재 사진처럼 표기
5. 촬영일 미확인 사진을 최신이라고 주장
6. AI 생성 이미지를 실제 사진으로 위장
7. 원본 사진을 확인하지 않고 설명 작성
8. 언론사 사진을 출처만 달면 자유롭게
   사용할 수 있다고 가정

사진 저작권 등급:

A:
네이버 공개 재게시 이용권이
명확히 확인된 사진

B:
출처는 확인됐지만
재게시 허락이 불명확한 사진

C:
재게시가 금지되거나
이용 조건을 충족하지 못하는 사진

공개 게시용 최종 이미지로는
A등급만 확정할 수 있다.

A등급 사진 5장이 확보되지 않으면
사진 요건 미충족으로 보고한다.

B/C 사진 파일을 무단으로
최종 미리보기 ZIP에 포함하지 마라.

미리보기에서도 무단 재배포를 피하기 위해

원본 링크와 후보 정보로만 제시하고,
게시 가능한 이미지와 구분하라.

모든 이미지를 글 마지막에
몰아서 보여주지 마라.

원고에 정해진 삽입 위치를 따른다.

사용자는 HTML을 열어
블로그처럼 위에서 아래로
스크롤하며 완성된 글을 확인해야 한다.

가능하면 사진·그래프와 HTML을
같은 폴더 구조로 묶어
인터넷 연결 없이도 정상 표시되게 한다.

모든 로컬 이미지 경로의
정상 작동 여부를 검증한다.

이미지가 누락되거나 잘못 연결된 경우
미리보기 완료로 처리하지 마라.

미리보기는 사전 시뮬레이션이다.

실제 네이버 화면을 확인하지 않았다면
100% 동일하다고 주장하지 마라.

==================================================
13. PDF 선택 제작
==================================================

HTML이 정상적으로 완성되면
필요에 따라 PDF를 추가 제작할 수 있다.

PDF는 필수가 아니다.

제작하는 경우:

- 모바일 화면 흐름 유지
- 바른히피 글꼴 적용
- 가운데 정렬
- 사진 위치 유지
- 그래프 위치 유지
- 표와 캡션 유지
- 불필요한 A4 보고서 여백 금지

PDF보다 HTML에서 확인되는
블로그형 화면을 우선한다.

14. 사진 자동등록 금지
==================================================

이번 Rev.16-1 작업에서
사진은 네이버 블로그에 자동등록하지 않는다.

절대 수행하지 말 것:

- 네이버 로그인
- 네이버 새 글 자동작성
- 네이버 사진 자동 업로드
- 네이버 그래프 자동 업로드
- 네이버 임시저장
- 기존 임시저장 글 수정
- 공개발행
- 예약발행
- Codex 자동 실행

사진은 사용자가 먼저 확인하고
필요하면 수동으로 등록하거나
다른 방식을 결정한다.

Work는 검토용 사진 자료를 제공하는 역할이다.
